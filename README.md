# WRHSE Product Photo Styler

A Codex skill for cleaning up, cutting out, and restyling merchant product photos in the WRHSE catalog illustration style while preserving visible product details.

## Install for Codex

Copy this repository folder into your Codex skills directory:

- Windows: `%USERPROFILE%\.codex\skills\wrhse-product-photo-styler`
- Other systems: `~/.codex/skills/wrhse-product-photo-styler`

Then start or refresh a Codex session and invoke `$wrhse-product-photo-styler` with the merchant's product photo. The connected agent needs an image generation/editing capability. Review the generated preview before replacing a listing image.
